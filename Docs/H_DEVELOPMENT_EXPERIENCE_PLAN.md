# 身體開發度的 H 體驗加強計畫（原作沒有的新功能）

2026-11-01 使用者提出，2026-11-02 再次確認並要求做成完整計畫。五種開發度各自改變 1 對 1 的體驗；0% 沒有影響，100% 效果最大，中間線性內插（下文的開發度記為 d，0～1）。

## 一、使用者規格（2026-11-02 原文整理）

| # | 開發度 | 一開始（0%） | 開發到 100% | 怎麼成長 |

| 4 | 陰部 | 最多插入 50%，只能在 20%～50% 之間抽插 | 可插入 90%；流的水量 200%；高潮持續時間 200% | 每在陰道內高潮一次增加 |
| 5 | 侍奉（口交） | 最多插入 30%（使用者另寫「10%～40% 之間抽插」，見第四節待決定） | 可插入 70%；吸住陰莖、雙頰凹陷、嘴巴拉長成馬臉、眼睛上翻、雙眼流淚，d 越高越明顯 | 每次射在她嘴裡 |

公式：

| 效果 | 公式 |
|---|---|
| 胸部大小 | 胸部縮放 = 1 + 0.5 · d胸 · (興奮值 / 100) |
| 陰道深度 | 上限 = 50% + 40% · d陰；抽送在 20%～上限之間 |
| 肛門深度 | 上限 = 40% + 50% · d肛；抽送在 20%～上限之間 |
| 口交深度 | 上限 = 30% + 40% · d口；抽送在 10%～上限之間 |
| 陰部流水量 | ×(1 + d陰)（肛交時噴水量用 d肛） |
| 高潮持續 | ×(1 + d)，d 取當下插入的那一處 |
| 乳汁量 | ×(1 + 2 · d乳) |
| 乳頭高潮噴發 | 高潮結束後再多噴 6 · d乳 秒 |
| 口交臉部 | 強度 = d口（吸吮時）：臉頰內凹、下半臉與嘴唇往前（馬臉，不是下巴變長）、眼睛上翻、雙眼流淚 |

場景內立即生效：場景內的開發度 = 進場時的值 + 10 × 本場在該處的高潮次數（口交為射在嘴裡的次數），上限 100；場景結束時 `h_session_end` 寫回同樣的增量。

## 三、實作與驗收階段

**P0 驗證已做的部分（不改程式）**
- 進 1 對 1，用 `/hscene {"dev":{...}}` 設 0 與 100，各量 60 秒：`her_drips`、`her_milk`、高潮時的 `ClimaxUntil` 長度（log 的 climax cry 到噴水停止）、乳頭多噴的秒數。結果寫進 `Docs/ONEONE_PERFECTION_CHECKLIST.md`。
- 口交 100：`face_cam` 近拍眼睛上翻與流淚；不明顯就列進 P2。

**P1 深度上限接回開發度**
- `UOKHScenePanel::AlignHim` 的 `Top`：陰道 `0.5 + 0.4·d陰`、肛門 `0.4 + 0.5·d肛`，下限 20%；口交維持。
- 這段和陰莖對位、包覆同一個函式，使用者已交給另一個 agent 處理陰莖；動手前先和那邊確認時機，避免互相蓋掉。之前移除限制是使用者為了除錯，接回要使用者同意。
- 驗收：開發度 0、50、100 各一次，正常位與後背位（肛門）`depth_top` 最大值分別約 50／70／90、40／65／90；側面截圖。

**P2 讓效果看得到**
- 眼睛上翻：若 P0 看不出來，加大幅度或加上翻白眼的眼型（原作有 ahegao 眼型可用）。
- 流淚：從眼角沿臉頰往下的淚痕（臉部液體遮罩，已有 `siru` 臉部體液可沿用），而不只是滴落的水滴。
- 乳汁、噴水的量：若 0 與 100 的差別在畫面上不明顯，改成每滴體積也變大，而不只是間隔變短。

**P3 成長的回饋（建議，待使用者決定要不要）**
- H 面板顯示五種開發度與本場增加量（例如「陰部 40% → 50%」）。
- 開發度跨過門檻（30、60、100）時她說一句對應台詞（ICU 文字表，`Localization/<lang>/*.toml`）。
- 事後記憶寫入「第一次插到最深」之類的事件。

**P4 全面驗收**
- 五種開發度 × 0／50／100，每個體位類型（正常位、後背位、騎乘位、口交）各一輪，側面與正面截圖，FPS；記進檢查表新的一節。
