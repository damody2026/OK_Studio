# 影輝大學城：3D 環境建模與地點互動計畫

建立日期：2026-10-24；更新日期：2026-10-25（Asia/Taipei）。  
版本：v0.3，依使用者最新範圍重新整理。  
狀態：建模與互動內容規劃；不代表模型、動畫或遊戲驗收已完成。

## 1. 本計畫的範圍

**重點是整個大學城的 3D 環境建模，以及每個地點能做什麼。** 場景要有完整建築、合理室內、細緻家具與可操作道具；兩個人進到同一個地方，能實際使用那裡的設備。

保留並深化共同用餐、自習、分工手作、輪流運動、陪伴練習、互拍照片、購物與住宿等雙人流程。每項互動描述兩人的位置、動作、道具與場景變化。

本版取代 v0.2 的系統規劃：移除雙向邀請、接受／婉拒／改期與商量流程，也移除 NPC 行程、關係成長、記憶、課業經濟、手機、存檔架構等章節。本文的雙人流程一律從「兩人已在場所、開始使用設施」描述，不規劃如何邀約。

## 2. 場景基線與保留內容

依交接與成果文件記錄，現有大學城具有以下基礎；本輪未重跑地圖或封裝查核。

| 基礎 | 後續建模方向 |
|---|---|
| 17 棟校舍、89 層室內、五座校門 | 保留既有建築與室內，逐房補足用途、家具、設備及細部 |
| 商店街、道路、運動區、公園與水岸 | 補強各區辨識度、連接動線與實際可用的設施 |
| H1 58 房、S18 3 房的汽車旅館 | 保留房型成果；逐房配置可用家具與設備，不把不同房型改成同一套房間 |
| 廁所大片鏡面與室內訓練鏡 | 保留鏡面、背板與反射配置，補足洗手、整理與練習所需空間 |
| 日夜照明、植栽、可讀招牌與既有石板路 | 沿用既有風格，避免無目的地重鋪地面或整城換材質 |

最新旅館交接仍列有待完成驗收；不能把舊成果的照片與通過紀錄當作新版本證據。既有資產只依實際盤點標記保留、修整、補件或新增。

## 3. 全城 3D 建模標準

### 3.1 城市尺度與動線

- 先整理總平面：街道、校門、步道、建築入口、樓層連接、公共設施與景點之間要連續可走。
- 維持平整的大學城基調；必要高差以實體台階、坡道、平台與支撐處理。
- 入口不能被植栽、家具、門扇或招牌擋住；車行與行人入口清楚區分。
- 主要步行動線容納兩人同行；窄路可前後通過，停留與拍照點另留位置。
- 景點、商店與校舍有清楚遠景輪廓，接近後看得到入口、用途與細節。
- 道路、校門、廣場、樓梯、走廊、房門、家具使用點串成完整通行路線，不只檢查單一房間。

### 3.2 建築外觀

每棟需檢查基座、立面、窗框、玻璃、門框、屋簷、屋頂、排水、欄杆與招牌。屋頂、遮棚、露台及高架平台要有合理結構，不能浮空或切進別棟建築。

校舍以學術與生活用途區分外觀；商店以櫥窗、雨棚、材質及店面陳列形成差異；住宿空間保留各自風格。重複模組可共用，但入口、主要立面與室內配置要有可辨識差異。

### 3.3 室內建模

- 每個公開房間至少有完整地板、牆、天花板、門窗、照明與用途相符的家具。
- 先配置使用空間，再放裝飾：椅子拉出、櫃門開啟、兩人交錯、攝影站位及設備操作都需有淨空。
- 依用途補踢腳板、窗簾、插座、通風口、置物架、掛鉤與小物，避免大房間只有幾張桌椅。
- 同棟不同樓層以房號、導覽、牆面與家具配置建立辨識；不以完全重複的長走廊填滿全部樓層。
- 開放與非開放空間清楚區分；對外呈現可使用的房間要有實際入口與內部內容。

### 3.4 材質、燈光與景觀

| 項目 | 建模與呈現要求 |
|---|---|
| 材質 | 木板、磁磚、石材、布料與金屬具合理尺度；粗糙度與法線符合材質，避免整屋同一張貼圖 |
| 接合 | 牆地、門框、窗框、台階、家具落地與磁磚邊緣接合完整；檢查共面閃爍與穿插 |
| 室內燈 | 光源對應實體燈具；桌面、櫃台、鏡前與走廊各有用途相符照明 |
| 夜景 | 保留可讀的夜間路線與招牌；室內能辨識人物和物件，不用過曝掩蓋暗處 |
| 鏡面／水面 | 有實體邊框、背板／池壁與合理厚度；反射方向及水位正確 |
| 植栽 | 樹冠、樹幹、土壤、花台與碰撞位置一致；避免穿牆、遮擋入口及座位 |
| 生活細節 | 菜單、書籍、餐具、運動用品、作品與布料依場所配置；不要到處複製同一組小物 |

### 3.5 雙人使用的建模契約

每個雙人設施都配置兩人的使用位置、接近方向、退出空間、道具放置點與動作範圍。相對、並排、輪流及操作／觀看四種布局分別設計。

| 使用方式 | 必須留出的 3D 空間 |
|---|---|
| 對坐用餐 | 兩張可使用座椅、腿部空間、各自餐具區、共享菜盤區及側邊起身通道 |
| 並排自習 | 兩人桌面、各自書本與手臂空間，椅背後有退座路線 |
| 分工手作 | 兩個工作位置、材料區、工具交接區及完成品展示區 |
| 輪流運動 | 操作區、旁觀／候位區、器材移動範圍與安全距離 |
| 陪伴練習 | 練習者完整動作區、觀看者位置與視線，不占用器材動線 |
| 拍照 | 被拍者站位、攝影者位置、雙人合照位置與足夠鏡頭退距 |
| 購物 | 兩人可停留的展示面、走道、試穿展示位置及結帳台前空間 |
| 住宿 | 房門至床、沙發、浴室、衣櫃及露台的連續路線，雙人使用時互不封路 |

所有尺寸先依實際人物膠囊、短／中／高身形及動作掃掠驗證，再定建模尺寸；不以縮小人物、穿牆或瞬移補救空間不足。

## 4. 全城分區建模與地點互動

以下以用途分類對應既有建築。未確認存在的工作室、器材或店型列為補建候選，先盤點再決定放置地點，不視為已完成資產。

### 4.1 校門、廣場、道路與公共交通空間

**3D 重點：** 五座校門的主次辨識、校名與校徽位置、圍牆收邊、導覽牌、守衛亭外觀、廣場鋪面、花台、雨棚、座椅、自行車架、站牌、候車亭與路口交通設施。保留既有良好石板路，補斷裂銜接與不合理高差。

| 地點 | 單人可做 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|---|
| 校門與導覽牌 | 看地圖、查看樓棟方向 | 並排查看 → 指向同一地標 → 走向對應出口 | 可近看的導覽圖、兩人站位、指示動作空間 |
| 廣場與長椅 | 坐下、看景、喝飲料 | 分別就座 → 坐談／一起喝飲料／看景 → 起身 | 可坐椅面、腿部空間、杯子放置點 |
| 候車亭 | 坐下、查看路線牌 | 並排候車、看路線、互拍站牌旁照片 | 座椅、遮雨棚、路線牌、拍照位置；不在本計畫展開交通系統 |
| 門與電梯 | 推拉門、按鈕、選樓層 | 一人操作、另一人等候 → 兩人通過／進出 | 正確門軸、門扇淨空、電梯轎廂及樓層門 |

### 4.2 教學樓、教室與行政空間

**3D 重點：** 保留 17 棟、89 層既有空間，逐層建立房間清單。教室、討論室、系辦與實驗室各有對應家具，補講台、板面、投影、窗簾、儲物櫃、房號、樓層導覽與完整樓梯扶手。

| 地點 | 單人可做 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|---|
| 一般教室 | 坐下閱讀、寫筆記、使用板面 | 並排自習 → 各讀各的 → 指書討論 → 收書起身 | 雙人相鄰座位、書本、筆、筆記本、桌面掛點 |
| 討論室 | 看板、閱讀資料 | 一人指板解說、另一人坐看 → 交換位置 → 一起整理資料 | 討論桌、可書寫板面、資料與站立解說區 |
| 實作／實驗室 | 觀察展示設備、操作指定器材 | 一人操作、另一人觀察／記錄 → 交換角色 | 依學院用途配置器材；只開放有明確操作方案的設備 |
| 行政櫃台 | 看公告、拿表單、使用書寫台 | 一人使用櫃台、另一人在旁等候 → 一起查看表單 | 櫃台、表單架、書寫台、等候座位；不規劃學籍規則 |

### 4.3 圖書館、閱覽室與書店

**3D 重點：** 書架尺度、分類標示、端架陳列、閱讀桌、個人座位、雙人桌、靠窗閱讀區、借還櫃台與燈光。書架之間保留兩人停留及轉身位置。

- 單人：瀏覽書架、抽取書本、翻閱、坐讀、放回書本。
- 雙人自習：兩人就座 → 各自放書 → 閱讀／寫筆記 → 指出書中內容 → 對方觀看 → 收拾。
- 雙人找書：一人抽書 → 另一人在旁看封面／內頁 → 交給對方翻閱 → 放回或帶到閱讀桌。
- 需要可拿取書本與靜態背景書分開；可用書架的抽取位置、手部高度及書本厚度配合動作。

### 4.4 社團、手作、音樂與舞蹈空間

**3D 重點：** 依實際用途布置工具牆、材料櫃、工作桌、作品架、樂器、譜架、練習鏡、地板標記與觀看座位。料理、陶藝等特殊工作室先確認既有場地與設備，作為補建候選。

| 地點 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|
| 手作工作桌 | 分坐兩側 → 一人整理材料、另一人組裝 → 遞工具／接零件 → 合作完成 → 擺上展示架 | 分離工具與材料、半成品／成品狀態、交接點、雙工作位置 |
| 畫室 | 一人畫、另一人觀看或擔任模特 → 展示畫作 → 交換觀看位置 | 畫架、畫布、畫具、模特椅、觀畫距離 |
| 料理工作桌（候選） | 一人備料、另一人拌料／料理 → 裝盤 → 一起吃 → 整理 | 流理台、砧板、碗盤、可分離食材、加熱設備與洗槽 |
| 音樂室 | 一人演奏、另一人坐聽 → 交換演奏；具備資產時可合奏 | 可用樂器、座椅、譜架、演奏與觀看位置 |
| 舞蹈室 | 一人示範、另一人觀看／跟練 → 並排練習 → 到旁邊休息 | 鏡牆、扶手、連續地板、完整肢體活動區、休息椅 |

單人仍可使用工作桌或練習設備。旁觀者要有相符觀看姿勢與視線，不能站在示範者動作範圍內。未有樂器、料理或手作動作時，標記待製作，不以空手待機冒充。

### 4.5 咖啡店、餐廳、食堂與戶外用餐

**3D 重點：** 每家店有自己的門面、櫥窗、菜單、點餐台、取餐台、桌椅、餐具、飲料與店內照明。室內對坐、並排靠窗與戶外座位使用不同布局。後場可依可見範圍配置，公開用餐區必須完整。

| 地點 | 單人可做 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|---|
| 販賣機／飲水機 | 操作按鈕、取飲料、補水 | 一人操作 → 各拿一份 → 遞交飲料 → 站飲／帶到座位 | 按鈕、出貨口、杯／瓶、取物與手持位置 |
| 咖啡店 | 看菜單、取餐、坐喝 | 兩人就座 → 放飲料與點心 → 喝飲料、吃點心、坐談 → 收杯起身 | 咖啡杯、杯碟、點心盤、雙座位與桌面分區 |
| 餐廳／食堂 | 取餐、使用托盤、坐下用餐 | 分別放餐 → 各自吃飯 → 從共享菜盤取食 → 用餐後收拾 | 托盤、餐具、個人餐點、共享菜盤、進食動作 |
| 戶外野餐 | 放餐盒、坐下用餐 | 一人鋪放用品、另一人擺餐 → 一起吃 → 分工收拾 | 野餐桌／墊、籃子、餐盒、垃圾收納用品與地面坐姿空間 |

共同用餐要看得到兩人各自取食、餐具與食物。分享餐點是具體的取放動作；不以同時播兩個空手坐姿算完成。本文不規劃價格、扣款或訂單系統。

### 4.6 商店、服飾與日用品空間

**3D 重點：** 櫥窗、貨架、商品陳列、可拿取商品、櫃台、購物籃、包裝區、試衣間與全身鏡。可互動商品與純展示商品清楚分層，避免所有商品都只有貼圖。

- 共同購物：兩人在展示面前停留 → 一人拿起商品 → 另一人觀看 → 交接／放回／放入購物籃 → 到櫃台擺放商品。
- 服飾試穿：一人在試衣間更衣，另一人在外等候 → 出來展示 → 在鏡前轉身查看 → 還原或換另一套；只有實際支援的衣物才可試穿。
- 禮品包裝：一人選取商品並放上包裝台 → 另一人協助包裝／拿盒 → 完成後交接。
- 單人可瀏覽、拿起、查看與放回商品；雙人流程重點是一起看、展示與交接，不展開金錢與背包系統。

### 4.7 球場、跑道、健身與休閒遊戲

**3D 重點：** 球場標線、球網／籃框、圍網、看台、跑道、器材支撐、地墊、飲水點、器材架、毛巾架與休息座位。器材操作區不能被觀眾座位或裝飾侵占。

| 地點 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|
| 跑道 | 並排慢跑／前後跑 → 到休息區補水 → 一起伸展 | 連續跑道、起終點、補水處、伸展淨空 |
| 籃球場 | 一人投籃、另一人撿球／傳球 → 交換角色 → 場邊休息 | 可動球、籃框、撿球範圍、傳接球動作 |
| 桌球場 | 兩側就位 → 發球／回球 → 撿球 → 再開始 | 球桌、球網、球拍、球與擊球範圍 |
| 健身區 | 一人使用器材、另一人在旁觀看／計數 → 交換 → 放回器材 | 配重或活動部件、手腳接觸點、旁觀位置 |
| 伸展／瑜伽區 | 兩張墊上並排練習；或一人示範、另一人跟練 | 墊子、鏡面、全身動作淨空 |
| 桌遊／遊戲機（候選） | 各就位 → 輪流操作／共同操作 → 完成一局 → 整理 | 可用按鈕／棋子／牌、手部操作範圍與觀看位置 |

輪流運動要有真正的操作者與等候者位置；不是兩人永遠同步揮動。器材若沒有可用動作或玩法，列為待補，不把場景擺設宣稱為可玩設施。

### 4.8 公園、花道、水岸、觀景與攝影

**3D 重點：** 花樹、土壤與花台、步道轉折、涼亭、岸邊護欄、釣魚平台、台階、夜間燈具與可停留的觀景面。景觀同時考慮行走視角、坐姿視角與雙人合照構圖。

| 地點 | 雙人流程 | 必要模型／操作部件 |
|---|---|---|
| 花道／水岸 | 並行散步 → 停在景物旁觀看 → 坐到附近休息點 | 可同行路線、觀景站位、連續座椅動線 |
| 涼亭／避雨處 | 兩人進入 → 並排或對坐 → 看景／喝飲料 | 完整屋頂與支柱、座位、杯子放置區、不漏接的地坪 |
| 釣魚平台 | 各自下竿；或一人釣、另一人觀看 → 收竿／展示漁獲 | 釣竿、魚線、浮標、座位、竿架、水岸安全距離 |
| 互拍照片 | 一人就站位、另一人持相機拍攝 → 查看照片姿勢 → 交換攝影者 | 相機／手機道具、站位、攝影退距、可辨識背景 |
| 雙人合照 | 兩人並排／相對做姿勢 → 自拍或固定相機拍攝 → 離開站位 | 自拍手持姿勢或相機架、雙人姿勢、前景遮擋檢查 |

互拍與合照是不同流程，分開配置動作和鏡頭位置。照片系統本身不在本計畫展開，只列所需畫面、道具及操作。

## 8. 驗收標準

### 8.1 3D 環境

- 外觀、入口、屋頂、牆地與樓梯有合理結構；無已發現的浮空、嚴重穿插、共面閃爍與通行阻擋。

- 材質尺度正確，日夜都能看清用途與操作部件；鏡面與水面實際呈現正確。
- 每個使用點能正常走到，雙人可各自就位及退出，門與抽屜開啟不封死通道。
- 檢查代表性短／中／高身形的坐姿、手部、腿部與器材接觸，不靠縮人或穿牆補救。

### 8.2 雙人流程

| 流程 | 通過條件 |
|---|---|
| 共同用餐 | 雙方各有餐點、餐具與相符取食動作，可正常擺放與收拾 |
| 共同自習 | 兩人都能坐讀、寫字、指書與觀看，不互穿桌椅 |

| 輪流運動 | 操作、觀看、器材與交換位置正確，不只有同步待機 |
| 陪伴練習 | 練習動作完整，觀看者視線與站位合理，能交換角色 |
| 互拍照片 | 拍攝者和被拍者角色清楚，可交換；雙人合照另有對應姿勢與構圖 |
