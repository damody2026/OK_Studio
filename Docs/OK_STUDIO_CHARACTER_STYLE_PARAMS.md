# 角色風格：參數盤點

2026-11-05，F 組，U178。風格滑桿（-1 寫實、0 照卡片、1 Q 版）動了哪些參數、哪些不動、為什麼。OK Studio 的狀態窗與 `CardReaderDevelopment.cmd` 的「角色風格」分類共用同一份程式 `OKStudioCharacterStyle.cpp`。

## 四層做法

| 層 | 做法 | 程式 |
|---|---|---|
| 滑桿 | 把卡片的滑桿往風格目標拉：`值 += |風格| × 0.75 × (目標 − 值)`，保留卡片的個性 | `OKStudioStyleSliders` |
| 骨骼 | 滑桿管不到的地方，用 `FOkSession::SetStyleBones` 疊在卡片的 ABMX 上，風格 0 時還原 | `OKStudioStyleBones` |
| 整體縮放 | 身高不用身高滑桿，用角色整體等比縮放 | `OKStudioStyleScale` |
| 抬高 | 腿長改變後把角色抬回地面 | `OKStudioStyleLift` |

身高滑桿同時改 `cf_a_height` 和補償用的 `cf_a_height_aid`，手、腳、頭不跟著長，所以不用它。

## 寫實端：頭不變小，頭以下變長

使用者 2026-11-05 定的方向：頭保持接近卡片大小，頭以下變長、變瘦長。

1. 頭部滑桿把頭縮到 `Heads` 頭身（公式：身高 `146.6 + 18.06h` cm，頭 `20.27 − 1.5h + 3.2v` cm）。
2. 角色整體放大 `卡片頭 ÷ 風格頭` 倍，頭回到卡片大小，身體跟著變長。
3. 身體各段用皮膚骨骼 `cf_s_*` 縮回 `1 ÷ 倍率 × 寬度倍數`，關節骨骼用 `pos` 往內收（單位公尺：大腿 0.0806、手臂 0.094）。
4. 手臂長度用 `ArmGrowth`、腿長用 `LegLength` 控制。
5. 頭再用 `cf_s_head` 等比放大到 `HeadSize` 倍，所以量到的頭身會低於 `Heads`（13 張卡約 6.9～7.7 頭身），身高約 195～243 cm。

ABMX 的 `pos` 是 `bp × length + pos`，左右號相反。JSON 不能寫 `.88`，開頭少 0 會整份丟掉。

## 可調數值

`FOKStudioStyleTuning`，不用重編。Studio 用 `studio_style_tuning`（控制操作 `style_tuning`）；CardReader 用「角色風格」分類的滑桿，存在 `Saved/OKStyleTuning.json`，四捨五入到小數第二位；主控台 `ok.GalleryStyle <鍵> <值>`。

| 鍵 | 預設 | 意思 |
|---|---:|---|
| `heads` | 11 | 頭身上限，頭部滑桿依此計算 |
| `head_size` | 1.4 | 頭對卡片的倍數 |
| `hips`、`shoulders`、`upper`、`waist` | 1.4、1.4、1.45、1 | 臀、肩、上半身、腰寬對卡片的倍數 |
| `upper_arm`、`forearm` | 1.55、1.6 | 大手臂、小手臂粗細 |
| `thigh`、`calf` | 1.3、1.3 | 大腿、小腿粗細 |
| `bust`、`hem` | 1.2、1 | 胸圍、衣服下擺寬 |
| `leg_length` | 1 | 腿長對角色放大的倍數 |
| `arm_growth` | 0.7 | 手臂保留多少放大量 |
| `breast` | 0.85 | 寫實端胸部滑桿目標 |
| `real_jaw` | 0.33 | 中等下巴的寫實強度，見下節 |
| `real_face` | 0.6 | 眼睛、鼻子、嘴往寫實目標走多少 |
| `real_chin`、`chibi_chin` | 0.15、0.15 | 寫實端、Q 版把下巴尖磨圓多少 |
| `chibi_head` | 0.8 | Q 版頭對頭部滑桿結果的倍數（`cf_s_head`），使用者 2026-11-05 定 |
| `chibi_jaw` | 0.1 | Q 版最多加寬下巴滑桿多少 |

## 下巴

**寫實強度依卡片決定。** `強度 = real_jaw + 0.74 × ((下巴寬 + 臉頰寬) ÷ 2 − 0.04)`，限制在 0.1～0.7。作用在臉寬、臉下部寬、下巴下部上下、下巴上下、下巴寬、臉頰寬、臉頰前後、臉頰上下。

使用者看圖定的值：貞德 0.15（下巴 0.00、臉頰 −0.40）、優香 0.5（0.30、0.25）。臉寬不是主因：貞德臉寬 0.55 但下巴與臉頰本來就窄，再往窄的目標拉就更尖。

**尖端用 `下巴尖上下` 磨圓。** 下巴尖往下 `圓度`、寬度加 `圓度 × 2`。特寫比較：`下巴尖上下` −0.3 時尖端明顯變鈍，`下巴尖寬度` 就算 1.2 也只有一點差別。

**C000、C050 偏尖的原因：** 下巴強度降到最低還是尖，因為卡片本身尖端就是 V 字，再加上五官上移把下半臉拉長，所以另外有 `real_face` 與尖端圓度。

**Q 版不再加寬已經寬的下巴。** 臉寬、臉下部寬、下巴寬、臉頰寬最多比卡片多 `風格 × chibi_jaw`。

## 胸部

- Q 版：滑桿最多縮到卡片的一半，本來就小的卡以 0.15 為目標，不會變大。
- 寫實：往 `breast` 拉，不設罩杯上限（使用者 2026-11-05 決定）。

## 手臂旁支與剛性配件

`cf_d_arm01～03`、`cf_d_forearm02`、`cf_d_wrist` 是掛在手臂關節下的旁支，手臂長度要一起改，否則手掌骨往手肘縮時皮膚留在原地。

配件是烘在元件空間的剛性網格，每幀用 `UpdateRigidFollowers` 跟著掛點走。掛點的縮放各軸不同時（手臂變粗但長度不變），舊做法把比例套在元件座標軸上，離原點越遠的配件被甩得越遠：雷電將軍手腕橫向 1.18 倍，袖口滑到前臂中段，領結也不見。現在繞骨骼旋轉、三軸用同一個平均比例，掛點本身的位置是精確的。

## 限制

- 頭身公式用身高與頭部滑桿的量測值，卡片自己用 ABMX 改過頭的話不在公式內。
- 只改形狀，皮膚、材質、光影沒有寫實化。
- 配件用平均比例放大，不會跟著手臂只變粗不變長。
- 下巴強度公式由貞德、優香兩張卡的值定出，其他卡是推算，使用者看過 13 張對照後接受。
- CardReader 的下巴滑桿用貞德走 MCP 的 `style.*` 測過，沒有用滑鼠拖過。
- 臉上的橘色色塊在風格 0 就有，疑似頭髮陰影，沒有查。
