# 汽車旅館 61 房型「像官網」修正計畫

日期：2026-10-25。使用者回饋：「建模建出來跟官網房間完全不像」。本檔是盤點結果與修正計畫，**尚未動任何模型或地圖**。

## 一、盤點方式

- 新增 `Tools/fetch_street_city_motel_reference_photos.lua`：依 `motel-v1/reference-catalog.json` 下載每間房前 3 張官網照片（182/183 張成功，`motel-v1/reference-photos/`，只留本機比對用）。
- 新增 `Tools/build_street_city_motel_reference_compare.lua`：每頁 2 間房，上排官網 3 張、下排封裝版遊戲（白天床位／夜間床位／浴室），共 31 頁 `motel-v1/reference-compare/compare-01..31.jpg`。
- 31 頁全部逐頁看過。

## 二、結論：不像的根因

`Tools/build_street_city_motel_suites.lua` 對 61 間房用**同一個程序模板**：

| 元素 | 現況 | 官網 |
|---|---|---|
| 鏡頭看到的主體 | 每間都是同一張白色雙人床＋兩個木床頭櫃＋同款檯燈，站在空曠淺色木地板上 | 主角多半是**客廳區**：大型歐式沙發組、大理石圓茶几、電視牆、按摩椅；床常在後景 |
| 牆面 | 只有床後一面「背牆」換色，套 8 種圖案（雙金環＋柱、拱、金色螺旋、竹葉、豎條＋菱形、四柱床…），其餘三面米白 | 整間包覆：深色壁紙、軟包、鏡面、馬賽克、磚牆、木格柵、壁畫 |
| 天花 | 平頂＋同一個環形吊燈 | 多層凹槽天花、LED 燈帶（紫／粉／藍）、水晶吊燈、圓頂、鏡面天花、斜木天花 |
| 地板 | 全部同款淺木板 | 深色木地板、黑白大理石拼花、地毯、磁磚 |
| 照明氣氛 | 明亮均勻、白天感 | 暗、暖色、霓虹強調色，夜店／宮廷感 |
| 浴室 | 每間同一個白色洗手台＋金框鏡＋紅框掛畫 | 按摩浴缸、黑色石材、玻璃隔間、造型浴缸（貓腳浴缸、圓形石砌浴缸） |
| 泳池房 | 床在前景、泳池小小在後面，池磚是單色 | 主角是泳池本身：紅白條紋馬賽克牆、藍黃波浪池底拼花、天窗、壁畫、吊床 |
| 顏色 | 用 1 個 accent 色決定房間 | 每間有完整配色與材質組合 |

另外三個小問題：

- 主題招牌元素多半沒做：巨型心形軟包座（紅磨坊）、銀河發光牆（杜拜）、圓形鳥籠椅（峇里島）、球形光纖簾＋鏡面天花（夏威夷）、劇場電影海報（華納威秀）、撲克霓虹（幻鏡撲克）、透明水柱（月球漫步）、鹿角吊燈與書牆（66號公路）、黑紗四柱床（黑色狂想曲）。
- 拍攝鏡頭固定從床尾看床頭，官網多從入口看客廳全景，對照時更顯不像。
- WeGo 房型官網有完整照片，但只取了第一張大圖做參考，其餘兩張是縮圖。

## 三、修正方向

不再用「一個模板換背牆」。每間房依官網照片建**房型專屬配置**（仍是原創改編、推導尺寸，不是一比一復刻），分層做：

1. **房型規格表（新 `motel-room-specs.json`）**：61 間各寫一份，由人看官網照片後填入，不由程式猜。欄位：
   - 區域配置：客廳區／床區／浴室區／泳池區的相對位置與大小。
   - 牆面：四面各自的材質類型（壁紙花紋、軟包、鏡面、馬賽克、磚、木格柵、壁畫）與顏色。
   - 天花：類型（平／多層凹槽／圓頂／鏡面／斜木）、燈帶顏色、主吊燈類型。
   - 地板：材質（深木／淺木／黑白大理石拼花／磁磚）＋地毯。
   - 家具組：沙發款式（歐式金框軟包／現代弧形／L 型）與數量、茶几、按摩椅、梳妝台、電視牆。
   - 床：形狀（方／圓）、床頭板款式、是否四柱／帳幔。
   - 浴室：浴缸類型（按摩方缸／圓形石砌／貓腳／泳池）、石材顏色、玻璃隔間。
   - 招牌元素：每間 1～3 個（例：心形軟包座、銀河燈牆、鳥籠椅）。
   - 燈光：主色溫、強調色、亮度等級。
2. **元件庫擴充**：把共用零件做成可參數化的組件，讓不同房間組合出不同樣子。
   - Blender 程序建模：凹槽天花＋燈帶、多層造型牆板、軟包菱格、木格柵、磚拱、鏡面牆、大理石拼花地板、圓床、四柱帳幔床、貓腳浴缸、圓形石砌浴缸、電視牆櫃。
   - 有機或複雜家具（歐式金框沙發、鳥籠椅、心形座、按摩椅、水晶吊燈、鹿角吊燈）：用 Tripo3D 生成，每件不超過 30 點，同樣經 instant-meshes-rs remesh。同類可跨房共用，但每間至少要有自己的招牌件。
   - 牆面圖案（壁紙、壁畫、馬賽克、銀河、撲克霓虹）：做 2K PBR 貼圖。
3. **燈光**：每間房依規格表放燈帶、吊燈與檯燈點光，夜間偏暗暖；不再只靠全域光。
4. **拍攝**：鏡頭改成「入口看客廳全景」＋「床區」＋「浴室」＋「招牌元素」四張，和官網構圖可比。
5. **泳池房**：重做池區：紅白條紋馬賽克牆、波浪拼花池底、天窗、壁畫、吊床；床退到側邊。

## 五、限制與需要決定的事

- 仍是依官網風格的原創改編，不會逐件複製官網家具或商標（例如電視上的 MORE／WeGo 字樣不做）。
- 房型格局目前是統一的長方形套房，官網有些是長廊、L 型或挑高；樣板階段先確認要不要改格局（會影響 H1 建築內的房間外框與走廊）。
- 生成家具估計每間 2～4 件 Tripo（≤30 點），61 間約 150～250 件，需要使用者同意點數預算。
- 既有 122 件房間飾品保留，配合新家具重新找擺放點。
